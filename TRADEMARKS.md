# MORDECAI Trademark Policy

This document describes the intended treatment of the MORDECAI project name and related branding.

> This policy is a project policy draft, not legal advice and not a statement that any particular mark has been registered. Formal trademark registration and jurisdiction-specific enforcement should be reviewed by qualified counsel.

## Marks

The project currently uses or may use the following identifiers as project branding:

- **MORDECAI**
- **MORDEC·AI**
- MORDECAI logos, icons, visual marks, and distinctive project artwork

Copyright licensing of MORDECAI source code does **not** grant permission to imply endorsement, sponsorship, certification, or official status.

The GNU Affero General Public License applies to covered source code. Trademark rights are separate from copyright rights.

## Allowed uses

Without separate permission, you may generally use the MORDECAI name truthfully to:

- state that software is compatible with MORDECAI;
- state that a project is based on or derived from MORDECAI;
- link to or discuss the MORDECAI project;
- describe an unmodified official distribution accurately;
- identify the origin of code in notices required by its license.

Examples:

- `Compatible with MORDECAI`
- `Based on the MORDECAI project`
- `A fork of MORDECAI`
- `Uses the MORDECAI protocol`

Such use must not imply that an unofficial fork, network, service, token, company, or product is operated, approved, or endorsed by the MORDECAI project.

## Uses requiring permission

Unless applicable law independently permits the use, obtain permission before using MORDECAI branding:

- as the primary name of a commercial service;
- as the primary name of an independent hosted network;
- in a company or organization name;
- in a domain intended to appear official;
- for a token or asset presented as the official MORDECAI asset;
- on merchandise presented as official;
- in a way likely to create confusion with the official project or network.

## Forks

Forking the source code under its software license is allowed.

An independent fork should use a clearly distinct product/network name.

Good:

> Aster Network — based on MORDECAI

Problematic:

> MORDECAI Cloud  
> Official MORDECAI Pro  
> MORDECAI Network 2

unless explicitly authorized.

## Modified distributions

A modified distribution may accurately state its origin, but it should clearly disclose that it has been modified and is not an official MORDECAI release.

Do not remove copyright or license notices required by the software license.

## Compatibility claims

Compatibility claims must be factual.

`MORDECAI-compatible` is preferable to branding an independent implementation simply as `MORDECAI`.

Compatibility does not imply certification unless an official certification program is created.

## Domains and social identities

Domains, package names, repository names, and social identities that could reasonably be mistaken for official MORDECAI infrastructure should not be used to impersonate the project.

## Logos

Official logos may receive more restrictive usage guidelines once a final visual identity exists. Until then, do not use project artwork to imply official status for an independent service.

## No restriction on truthful discussion

This policy is not intended to prevent nominative, descriptive, journalistic, educational, comparative, or other uses allowed by applicable law.

## Contact

A dedicated trademark contact will be published before formal commercial operation.

Until then, trademark questions should be directed through the project's official repository or project website.

---

The purpose of this policy is simple: the code may be forked according to its license; the identity of the official MORDECAI project must remain distinguishable from those forks.
